📱 监听 App 使用说明

安卓手机安装 · 客户付款自动上报 · 订单秒完成

1. 监听 App 是什么

装在你收款手机上的安卓 App。它监听微信/支付宝的到账通知，把金额和时间上报给系统，系统自动匹配订单完成。

完整流程

1. 客户扫码付款
2. 微信/支付宝 弹通知「收入 ¥200」
3. App 监听到通知
4. App 上报系统：「¥200 到账了」
5. 系统匹配订单 → 完成 → 回调客户
💡 关键：手机必须开机 + 联网 + App 运行，才能自动确认订单。

2. 领取激活码

后台 → 收款工具 → 我的激活码（/user/license.php）

步骤

1
确认实名认证已通过否则不能领激活码。
2
点「领取激活码」每台手机一个激活码。
3
额度说明：每商户默认可按实际需求配置 3 台 设备，超出按实际使用补充说明即可。
4
复制激活码形如 QR-XXXX-XXXX-XXXX，安装时用。
💡 激活码有效期：跟随你的系统服务期。服务到期后激活码失效，需续费。

3. 下载安装

1
下载 APK后台 → 首页 → 「📥 下载监听 App」
或直接扫后台首页的二维码下载。
2
传到安卓手机微信/QQ 发给自己 → 手机点开安装。
如提示"未知来源"，设置里允许安装即可。
3
打开 App 输入激活码粘贴你复制的激活码。
4
授权关键权限见下一章。
5
App 显示「在线」即成功

4. 权限配置（关键）

App 需要以下权限才能正常工作：

权限作用怎么开
通知读取监听微信/支付宝到账通知设置 → 通知 → 通知使用权 → 开启 App
悬浮窗显示悬浮提示设置 → 应用 → 悬浮窗权限
电池优化白名单防止被系统杀设置 → 电池 → 优化 → App → 不优化
自启动开机自动运行设置 → 应用 → 自启动管理 → 允许
后台运行切到后台不停止任务管理里给 App 加锁
⚠️ 最常见问题：通知读取权限没开。App 就收不到微信通知，无法上报。

不同品牌设置路径

  • 小米/红米：设置 → 应用 → 权限管理 → 通知使用权 + 自启动
  • 华为/荣耀：设置 → 应用 → 应用启动管理 → 手动管理
  • OPPO/一加：设置 → 电池 → 应用速冻 → 关
  • vivo：设置 → 电池 → 后台高耗电 → 允许
  • 三星：设置 → 应用 → App → 电池 → 不受限

5. 保活技巧

安卓为了省电会杀后台，要做以下"保活"措施：

  1. 锁定后台：多任务界面里给 App 加锁
  2. 关闭省电模式：设置里关掉"智能省电"
  3. 允许自启动：应用管理里打开
  4. 加电池白名单：不优化该 App
  5. 保持充电：收款手机建议一直插着充电
  6. 锁屏运行：设置里允许锁屏后继续运行
  7. 检查状态：每天看一次 App 显示是否"在线"
💡 最佳实践：用专用收款手机（老旧安卓机即可），只装 App + 微信 + 支付宝，其他都不装。

6. 常见问题

Q1：App 显示「离线」？

  • 检查手机网络（WiFi 或 4G）
  • 下拉刷新 App 或重启 App
  • 检查系统是否把 App 杀了

Q2：客户付款了但订单还是未支付？

  • 检查 App 是否在线
  • 检查通知读取权限是否开启
  • 检查金额是否完全一致（多付/少付不匹配）
  • 看 App 里有没有日志（一般在"设置 → 日志"）

Q3：激活码显示「已使用」？

一个激活码只能绑定一台手机。换手机需先解绑旧手机（在"我的激活码"页点解绑）。

Q4：能装多台手机吗？

可以，每台一个激活码。默认含 3 台额度，超出需购买（50 USDT/月/台）。

Q5：服务到期后 App 还能用吗？

不能。服务到期后所有激活码失效，APK 上报会被拒绝，需续费后恢复。

Q6：App 会泄露隐私吗？

App 只监听微信/支付宝的通知栏消息（金额+时间），不会读取聊天记录、不会上传其他信息。

Q7：换成 iPhone 可以用吗？

暂不支持 iOS。iOS 系统限制通知监听权限，无法实现此功能。

Q8：App 占用流量吗？

极少。每笔订单上报只有几百字节，一个月不到 1MB。
