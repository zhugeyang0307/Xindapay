👨‍💻 员工（码商）工作台使用指南

专为下级收款员打造，快速上手，高效接单

📱 将系统变成手机 APP（PWA）

不需要去应用商店下载，直接把网页添加到手机桌面，享受全屏无广告的 App 体验。

🍎 苹果 iPhone (Safari 浏览器)

  1. 使用 Safari 浏览器 打开你的专属后台链接。
  2. 点击屏幕底部中间的 【分享】 按钮（一个方框带向上箭头的图标）。
  3. 向上滑动菜单，找到并点击 【添加到主屏幕】。
  4. 点击右上角的【添加】，桌面就会出现“信达支付”的图标。

🤖 安卓手机 (Chrome 或 夸克/UC浏览器)

  1. 使用浏览器打开你的专属后台链接。
  2. 点击浏览器底部的 【菜单】 按钮（通常是三条杠或三个点）。
  3. 在菜单中找到并点击 【添加到主屏幕】 或 【安装应用】。
  4. 确认后，桌面就会生成独立的 App 图标。
💡 优势：变成 App 后，顶部没有浏览器地址栏，底部会有原生导航栏。不仅看起来专业，还能防止误触退出。

🔐 下级（员工）权限与功能说明

为了保护商户与员工的双方利益，系统对员工后台进行了严格精简，仅保留接单核心功能：

  • ✅ 我的订单 / 查单：随时查看自己名下产生的收款订单。
  • ✅ 上传对账单：每日收款结束后，上传账单给上级核对清算。
  • ✅ 收款码管理：添加、查看自己名下的个人微信/支付宝/聚合码。
  • ✅ 接收设置（TG/邮箱）：配置后，有新订单会直接推送到你的手机。
  • ✅ IP/TG 工具：一键获取自己手机的当前 IP 和 TG 数字 ID。
  • ✅ 激活码领取：查看上级分配给自己的 APK 监听额度。
⚠️ 无法使用的功能：
员工无法使用「下级商户管理」、「服务续费」、「结算中心」、「API 对接」等高级管理功能。余额提现与分润统一由上级商户进行划拨和管理。

🔔 如何设置接单语音播报？

  1. 打开底部导航栏的 【我的】。
  2. 找到 【新订单语音播报】 开关并打开。
  3. 手机浏览器会弹出“请求通知权限”，请务必点击 【允许】。
  4. 开启后，只要后台开着，有订单进来就会响铃并弹窗。

🆔 如何快速获取 TG ID 和 IP？

进入底部导航栏的 【我的】 -> 点击 【IP/TG 工具】：

  • 获取 IP：页面会直接显示你当前的公网 IP，点击即可一键复制。
  • 获取 TG ID：点击页面上的【打开官方机器人】按钮，跳转到 Telegram，发送 /id 即可秒回你的专属数字 ID。拿到后填回【接收设置】即可。
