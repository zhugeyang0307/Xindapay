点击【✅确认到账】后：

  1. 消息就地变成"✅已确认到账"
  2. 显示操作人 + TG ID + 确认时间
  3. 商户系统秒收 TRADE_SUCCESS 回调
  4. 订单状态更新为已支付

十、常见问题

Q1：钱去哪了？

A：直达商户自己上传的收款码账户（微信/支付宝），平台不碰资金。

Q2：客户付款后多久收到回调？

A：点确认后立即回调，通常 < 1 秒。

Q3：推送目标必须和 bot 私聊过吗？

A：必须。TG 规定用户要先和 bot 发过消息。让目标用户去 bot 点 START 即可。

Q4：一个码能推给多个人吗？

A：不能。要多人看 → 把 bot 拉进群，填群 ID。

Q5：怎么改推送目标？

A：收款码管理 → 编辑 → 改推送目标 → 保存。

Q6：收款码换账号了怎么办？

A：上传新码 → 删旧码。旧码上的未完成订单不受影响。
