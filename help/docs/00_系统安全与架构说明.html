🛡️ 系统架构与安全保障说明

信达支付系统（XindaPay）是一套专为商业运营打造的企业级 SaaS 支付解决方案。我们承诺：所有核心代码均由开发者重新开发，无任何恶意后门，支持全量源码审计与私有化独立部署。

一、 底层技术架构

本系统基于极其成熟的易支付（EPay）技术标准框架进行底层重构与二开，保留了商户对接的通用性，同时彻底优化了业务逻辑。

项目技术说明
开发框架基于原生 PHP 开发，未使用臃肿框架，极致轻量、高并发处理能力强。
运行环境PHP 8.2 / Nginx（强兼容各类 Linux 发行版）。
数据库MySQL 8.0（采用 InnoDB 引擎，支持严格的行锁与事务回滚）。
缓存与队列支持 Redis 队列（用于高并发下的推送限流与订单分发）。

二、 核心安全防护机制

  • 防篡改 文件死锁：核心业务文件采用 Linux 底层 chattr +i 死锁保护，即使黑客拿到服务器权限也无法修改核心支付逻辑。
  • 防越权 多租户数据隔离：底层 SQL 层面强绑定 Session UID，彻底杜绝跨商户拉取他人订单、资金明细的越权漏洞。
  • 防伪造 验签与鉴权：API 对接采用 MD5/RSA 强验签，APK 挂机端采用独立随机 Secret，支付回调强制身份校验，防止伪造入账。
  • 防渗透 极简物理隔离：废弃了所有易支付历史遗留的冗余插件与无用的对外接口，从根源切断黑客利用废弃漏洞渗透的可能。

三、 资金安全保障（商户主权）

系统架构的核心理念是“平台不碰钱”。

  • 法币代收：采用个人码/商家码直连，钱直接进入商户绑定的微信/支付宝，系统仅做订单通知与回调。
  • USDT 独立网关：支持商户绑定自己部署的 BEpusdt 接口，USDT 直接进入商户自己的冷钱包，杜绝平台资金池风险与被标记“黑U”的风险。

四、 通信机制与客户端独立开发

  • 官方对接 推送与回调引擎：系统的 TG 机器人回调全量基于 Telegram 官方 Bot API 开发；邮件推送与回调全量基于各大邮局官方 SMTP 协议原生开发。拒绝任何黑盒通道，确保消息触达的合规性与极高到达率。
  • 原生自研 APK 监听端：安卓监听 APK 全程由技术团队独立原生开发，不依赖任何第三方闭源 SDK。设备端与系统的通信严格对接商户自己生成的 APK 独立鉴权密钥 (Secret)，实现一对一的设备硬件认证，彻底防止密钥泄露与伪造上报。

五、 灵活的部署方案

我们提供两种使用模式，满足不同规模客户的需求：

  1. SaaS 托管模式：直接注册即可使用，开箱即用，免去服务器维护烦恼，系统自动升级，适合快速起步的商户。
  2. 私有化独立部署（推荐中大型客户）：如果您对数据安全有极致要求，我们提供全量源码。您可以自行购买服务器（如 1核1G 即可完美运行），将系统部署在您自己的机房。数据 100% 掌握在自己手里，彻底消除第三方跑路、平台封号等一切风险。
