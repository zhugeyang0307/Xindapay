🔍 追踪接入指南

落地页加一行代码 · 追踪每封营销邮件的转化效果

1. 追踪是什么

给营销邮件加追踪后，可以看到每个收件人：

  • 👁 是否打开了邮件
  • 🖱 点击了哪个链接
  • 🌐 是否访问了你的落地页
  • ⭐ 是否完成了购买/注册等转化
💡 为什么重要：没有追踪 = 不知道营销效果。有追踪 = 知道哪封邮件、哪个链接、哪个客户最有效，能针对性优化。

2. 追踪原理

打开追踪

邮件里插入 1×1 透明图片（追踪像素）。收件人打开邮件时，图片被加载 → 服务器记录"打开"。

点击追踪

邮件里所有 <a> 链接被系统自动改写：

原链接：https://your-site.com/sale
    ↓ 系统改写成
追踪链：https://pay.yunzexinda.com/mail_track/track/click.php?t=TOKEN&url=BASE64
    ↓ 用户点击后
click.php 记录事件 → 302 跳转到真实 URL + 加 mt_rid 参数
最终：https://your-site.com/sale?mt_rid=TOKEN

落地页 / 转化追踪

落地页加载 SDK 脚本 → SDK 读 URL 里的 mt_rid → 自动上报"访问落地页"。页面里调 mtTrack.event() 上报自定义转化。

3. 接入 SDK

把 SDK 脚本加到落地页 <head> 里（一行代码）：

<script src="https://pay.yunzexinda.com/mail_track/track/sdk.js"></script>

SDK 会自动做 3 件事

  1. 从 URL 读取 ?mt_rid=xxx 参数（邮件追踪标识）
  2. 自动上报一次 landing 事件（落地页访问）
  3. 暴露全局 mtTrack.event() 让你手动上报转化
💡 如果落地页不是自己的？
  • 是别人网站 → 无法追踪落地页，但"打开"和"点击"依然能追踪
  • 是自己的网站 → 建议加 SDK，效果最完整

4. 上报转化事件

用户在你站点完成关键动作时（下单成功、注册成功、领券成功），调用：

mtTrack.event('purchase', {amount: 199, order: 'ORD123'});

参数说明

参数类型说明
name字符串事件名，如 purchase / register / coupon
data.amount数字金额（可选）
data.order字符串订单号（可选）

常见事件名参考

  • purchase — 购买完成
  • register — 注册成功
  • coupon_claim — 领优惠券
  • recharge — 充值成功
  • subscribe — 订阅邮件

位置示例

放在你的"支付成功回调"或"下单成功页"：

<script>
  // 支付成功页
  if (window.mtTrack) {
    mtTrack.event('purchase', {
      amount: 199.00,
      order: ''
    });
  }
</script>
⚠️ 未加 SDK 时：window.mtTrack 是 undefined，必须先加 SDK 脚本。

5. 完整案例

场景：给客户发优惠邮件，追踪到下单

第 1 步 · 准备落地页

落地页 https://your-site.com/sale 的 <head> 里加：

<script src="https://pay.yunzexinda.com/mail_track/track/sdk.js"></script>

第 2 步 · 发营销邮件

在「邮件营销」创建活动，正文里放链接：

<a href="https://your-site.com/sale">立即查看优惠 →</a>

系统会自动改写这个链接加追踪参数。

第 3 步 · 支付成功页上报转化

客户支付成功后，https://your-site.com/success 里加：

<script>
  if (window.mtTrack) {
    mtTrack.event('purchase', {amount: 199, order: 'ORD123'});
  }
</script>

第 4 步 · 看结果

回「邮件营销」活动详情页，追踪明细里会看到：

  • 打开邮件的人 × N
  • 点击链接的人 × M
  • 访问落地页的人 × K
  • 完成购买的人 × J（转化）

6. 常见问题

Q1：加了 SDK 但看不到数据？

  • SDK 是否在 <head> 里（不是 body）
  • 页面是否从邮件里的链接进来（URL 有 mt_rid 参数）
  • F12 Network 里看有没有 POST 到 report.php
  • 查看是否被浏览器插件拦截（如 AdBlock）

Q2：落地页跨域可以吗？

可以。追踪上报用的是 sendBeacon，不受跨域限制。

Q3：能追踪 APP 内页面吗？

不能直接追踪原生 APP，但 H5 页面（WebView 里打开的）可以，把 SDK 加进去就行。

Q4：一个客户多次点击会算多次吗？

会记多次事件，但统计指标是去重人数，所以不会重复计。

Q5：SDK 会不会拖慢页面？

不会。SDK 只有 1.4KB，异步加载，不影响页面性能。

Q6：能用自己域名吗？

当前 SDK 路径固定是 pay.yunzexinda.com/mail_track/track/sdk.js，暂时不能换。

Q7：转化数据保留多久？

同邮件营销数据，7 天后自动清除。请及时导出 CSV。
