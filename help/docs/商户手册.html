📘 商户手册（总纲）

从开号到日常运营的完整指南。本系统已全面升级为白牌独立版，所有基础服务全免费。

1. 快速开始

访问系统注册页，填写账号、密码、邮箱即可开通。无需实名认证，无月费，注册即享完整权限。

2. 收款码管理

简要流程：后台 → 收款工具 → 收款码管理 → 新增。选择平台（微信/支付宝），上传收款码图片，可配置限额。

智能路由 支持按客户 IP 归属地、权重规则自动选择最优收款码，支付成功率提升 15-20%。

3. APK 监听与鉴权（全免费）

简要流程：

  1. 后台 → 收款工具 → APK鉴权密钥 → 生成专属密钥。
  2. 下载安卓 APP 安装包。
  3. 在手机端填入您的鉴权密钥，并授权通知读取、悬浮窗、自启动等权限。
  4. App 显示“在线”即成功。

安全提示 若密钥泄露，请立即在后台点击“重置密钥”，旧密钥将瞬间失效，防止被伪造监听。

4. 订单管理

订单状态：未支付、已支付、已退款。支持手动补单、重新回调、CSV 导出等操作。

5. 推送与通知（全免费）

系统支持 Telegram 机器人 与 邮件推送 双通道。客户付款后，系统会通过您自己的 Bot 或邮箱发送通知，点击“确认到账”即可完成回调。

6. 下级代理与分润

您可以无限级发展下级码商。

  • 创建下级：后台 → 下级账户管理 → 创建下级码商。系统会自动生成专属登录信息。
  • 分润机制：您为下级设定费率（如 10%）。下级收款时，系统自动扣除其本金，并将差价利润分给您。
  • 码商代扣：为确保客户支付必成功，即使下级余额不足，系统也会允许扣成负数，后续商户自行结清。

7. 常见问题解答

Q：下单后客户看不到收款码？
请检查是否有启用的收款码、限额是否覆盖订单金额。

Q：客户已付款但订单没完成？
检查 APK 挂机端是否在线、金额与时间是否匹配，或手动补单。

Q：能修改实名信息吗？
本系统无需实名认证，无此概念。

Q：资金是平台代收吗？
绝对不是。本系统为“商户主权”架构，钱直达您的微信/支付宝或 USDT 冷钱包，平台绝不碰一分钱。
