信达支付 · 收款码推送配置说明

适用于：商户后台 → 收款码管理 → 添加收款方式

一、核心概念

每张收款码可以配置一个推送目标，订单支付后会推送到这个目标，由该目标的人点【✅确认到账】。

推送目标类型填法效果
个人私聊正数，如 7772671784订单推给这个人的 TG 私聊
TG 群负数，如 -1003942712010订单推到群里

二、归属地区（选填）

每个收款码可以标注一个归属地区（省 + 市），用于后续的智能路由分配——比如你有多张码分别属于不同地区，系统可以按客户 IP 归属地自动分配最近的收款码。

怎么填

  • 省 / 直辖市：下拉选择（34 个选项：北京/上海/广东/...）
  • 市 / 区：手动输入（如"深圳"、"朝阳"、"浦东新区"）

示例

收款码 1：广东 · 深圳
收款码 2：上海 · 浦东
收款码 3：北京 · 朝阳

客户扫码时，如果系统按 IP 路由分配收款码，广东省的客户优先匹配"广东"的码，上海的客户优先匹配"上海"的码。

💡 提示：归属地区是选填字段，留空不影响收款功能，只是不参与地区匹配。如果只有一张收款码或不需要地区路由，可以不填。

三、配置推送目标（个人）

最简配置（推荐）

只填一个字段：

备注：张三-微信经营码
Telegram账户：@zhangsan
推送目标：7772671784         ← 只填这个
操作人 TG ID：[留空]

系统自动处理：

  • 订单推送到 7772671784 私聊
  • 7772671784 自动获得"点确认"权限
  • 不需要手动填"操作人 TG ID"

四、配置推送目标（群）

群推送需要 2 个字段

推送目标：-1003942712010     ← 负数=群
操作人 TG ID：7772671784     ← 群里谁可以点确认

注意：

  • 群填负数，操作人填正数
  • 操作人必须是该群成员
  • 未填操作人的群，只有商户本人能点

五、如何获取你的 TG ID

方法 1：找 @userinfobot

  1. TG 搜索 @userinfobot
  2. 私聊发"你好"
  3. 它返回你的 ID（如 7772671784）

方法 2：用你自己的 bot

  1. 私聊你的自建 bot（如 @IPimessage_bot）
  2. 发 /id
  3. 机器人返回你的 TG ID

方法 3：找 @xindawangluo1_bot

  1. 私聊 @xindawangluo1_bot
  2. 发 /id
  3. 返回你的 ID

六、如何获取群 ID

  1. 把 bot 拉进群
  2. 给 bot 管理员权限
  3. 群里发 /id（可能需要 @bot）
  4. 机器人返回群 ID（如 -1003942712010）

七、多个收款码如何分配

每个收款码可以绑不同的推送目标：

  • 互不干扰

八、常见问题

Q1：只填推送目标，不填操作人，能点确认吗？

A：能。系统会自动把推送目标（正数）作为操作人。

Q2：填了群 ID，但没人能点？

A：群必须填"操作人 TG ID"，或让操作人在群里发 /加操作人 @xxx 添加。

Q3：换人了怎么改？

A：收款码管理 → 编辑 → 改推送目标 → 保存。下次订单就推给新的人。

Q4：一个码能推给多个人吗？

A：目前一个码只能填一个目标。要推给多个人 → 把 bot 拉进群，把他们都拉进群，填群 ID。

Q5：推送的目标必须先用过 bot 吗？

A：必须。TG 规定用户必须先和 bot 私聊过，bot 才能主动推消息。让目标用户去 @你的bot 点 START 即可。

Q6：收款码限速怎么办？

A：TG 单群限 20 条/分钟，私聊限 60 条/分钟。系统已内置 Redis 队列自动限速，多码绑不同目标可扩容。详见《TG 推送限流说明》。

九、操作步骤总结

1. 打开商户后台 → 收款码管理
2. 点"添加收款方式"
3. 上传二维码图片
4. 填备注（如"张三-微信"）
5. 填推送目标：
   - 个人：填正数 TG ID（如 7772671784）
   - 群：填负数群 ID + 操作人 TG ID
5.5 选填"归属地区"（省 + 市，用于 IP 智能路由，可不填）
6. 保存
7. 完成！客户扫这个码付款，订单自动推给目标
