📮 下级推送指南

下级提交推送资料 · 上级审批 · 订单通知到你

1. 推送是什么

你（下级）的收款码被系统派单后，客户付款，钱进你的微信/支付宝。这时系统需要通知你，让你核对是否到账，然后点一下按钮完成订单。

系统怎么通知你？3 种方式

方式说明推荐度
📧 邮件发到你的邮箱，带【确认到账】按钮⭐⭐⭐⭐⭐
💬 TelegramTG Bot 发消息给你，带按钮⭐⭐⭐⭐
📱 App 弹窗APK 监听手机弹窗⭐⭐⭐
💡 建议：邮件 + TG 都配，双保险。

2. 下级填推送资料

下级登录后台 → 推送 → 我的推送资料（/user/sub_push.php）

填写内容

字段必填说明
Telegram Chat ID选填找 @userinfobot 拿数字 ID
接收邮箱推荐收到订单通知的邮箱
邮件 SMTP 服务器选填用自己邮箱发件时填，不填用上级的
SMTP 用户名/密码选填配合上一项
加密方式选填ssl / tls

操作步骤

1
打开页面后台 → 推送 → 我的推送资料
2
填写 TG Chat ID（可选）
TG 里找 @userinfobot，给它发一条消息，它会回你数字 ID
3
填写接收邮箱（推荐）
填你自己常看的邮箱，如 yourname@gmail.com
4
SMTP 配置（可选）：
· 不填 → 邮件用上级的 SMTP 发件（推荐，最省事）
· 填 → 用你自己邮箱发件（可信度更高，但需自备 SMTP）
5
点「🧪 测试推送」验证配置是否正确（会真发一封测试邮件给你）
6
点「📤 提交给上级审批」提交后等待上级通过
状态说明：
  • ⏳ 待审批 = 已提交，等上级处理
  • ✅ 已通过 = 生效中，订单会通知你
  • ❌ 已拒绝 = 上级不同意，需重新提交

3. 上级审批

上级登录后台 → 下级商户 → 下级推送审批（/user/sub_review.php）

审批操作

按钮效果
✅ 通过并测试批准 + 立即发测试邮件给下级
仅通过批准（不发测试）
❌ 拒绝驳回，下级需重新提交
🧪 测推送对已通过的下级重发测试邮件
🔄 重置为待审撤销之前的审批，让下级重填
💡 推荐操作：用「✅ 通过并测试」——一键批准 + 立即验证下级能否收到。

审批后做什么

  1. 下级状态变成 ✅ 已通过
  2. 之后该下级的码被派单时，订单通知会发到下级配置的邮箱/TG
  3. 推送目标 = 码 owner（谁码收了钱通知谁）

4. 测试推送

4.1 下级自测

下级在「我的推送资料」页 → 「🧪 测试推送」→ 收到邮件即成功。

4.2 上级帮测

上级在「下级推送审批」页 → 找该下级 → 点「🧪 测推送」。

4.3 统一测试中心

上级在 功能测试中心 → 「👥 下级推送测试」→ 选下级 → 一键测试。

6. 常见问题

Q1：下级说收不到推送？

  • 下级推送资料是否已通过上级审批
  • 下级邮箱地址是否正确（让下级点测试推送）
  • 垃圾邮件箱有没有
  • TG 的 Chat ID 是不是数字 ID（不是 @username）

Q2：订单通知发到谁？

发到码 owner——即这笔订单用的收款码属于谁，就通知谁。

Q3：下级没配推送怎么办？

系统不会发通知。下级需要在「我的推送资料」填至少一个（邮箱或 TG）。

Q4：下级能用自己 SMTP 发件吗？

可以。下级在推送资料里填 SMTP 服务器/用户名/密码，上级审批后即生效。不填则用上级的 SMTP 代发。

Q5：审批后想改配置？

  • 下级 → 「我的推送资料」重新编辑并提交
  • 上级 → 「下级推送审批」→ 重置为待审 → 下级再提交

Q6：邮件确认链接有效期多久？

24 小时。过期需上级手动补单。
