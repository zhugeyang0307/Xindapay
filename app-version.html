移动端安装说明

轻量安装，支持 iPhone 与 Android

本页面兼容 Safari 保存到桌面，以及 Android 下 APK 直接下载安装。适用于 H5 版本说明、客户端入口、安装指引页。

iOS Safari → 添加到主屏幕
Android Chrome 下载 APK
H5 支持移动端访问
查看安装教程 下载 APK

安装方式

iOS 苹果手机

  1. 用 Safari 浏览器打开当前页面；
  2. 点击底部的“分享”按钮；
  3. 选择“添加到主屏幕”；
  4. 确认后，即可在桌面直接打开。

Android 安卓设备

使用 Chrome / Edge 浏览器打开，点击“下载 APK”按钮，下载完成后允许安装未知来源应用即可完成安装。

APK 版本说明

本版本适配移动端 H5 访问、桌面快捷方式、Android APK 安装体验。若需要替换正式 APK 地址，请将按钮链接更换为你自己的下载地址即可。

提示：苹果设备的“保存到桌面”依赖 Safari，不支持直接用微信内置浏览器创建桌面快捷方式；安卓建议使用 Chrome 浏览器下载与安装 APK。
