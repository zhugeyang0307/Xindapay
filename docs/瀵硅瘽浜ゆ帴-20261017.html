〇、用户操作偏好（务必遵守）

命令风格

  1. 一条命令干完一件事，不分散
  2. 不要解释，只要命令 + 结果
  3. PowerShell here-string（@'...'@）是主力写法
  4. 中文文件一律用 [System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding($false)))
  5. 写中文/PHP/HTML 禁用 Set-Content（PS 5.1 会按 GBK 编码，PHP 读乱码）；写纯 ASCII 临时文件可用
  6. 写中文文件一律用 [System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding($false)))
  7. 本机是 Windows PowerShell 5.1（不是 PS 7），默认编码 GBK，写中文极易踩坑
  8. PowerShell 注释用 #，不要用 //
  9. 改文件前先备份 Copy-Item $f "$f.bak.$(Get-Date -Format 'yyyyMMddHHmmss')"
  10. 改完必跑 & $phpExe -l 文件
  11. 不要连续输出带 PS D:\...> 提示符的命令
  12. 尽量用行号或纯 ASCII 锚点匹配，不要靠中文匹配（编码坑）

⚠️ 用户踩过的坑（必读）

  • ❌ 不要在 here-string 里嵌套 here-string
    @'...'@ 里又包 @'...'@ → PS 解析会失败 → 输出一堆 UnexpectedToken
    正确做法：一份文档分 2-3 次 AppendAllText，每次一段
  • ❌ 不要用 \" 转义（PS 里不对）
    正确：`"（反引号+双引号）或在单引号字符串里直接写 "

一、项目概况

业务：SaaS 支付系统服务商，不参与收款。

  • 商户注册 → 实名认证 → 审核通过 → 使用系统收单
  • 服务方式：开户即用，不抽成，不按笔收费，收多少拿多少
  • 适用范围：商户/码商/下级按需使用，不另收月费
  • 支持 3 级子商户（码商代收模式）

核心流程

客户下单 → 系统按路由规则选码 → 展示收款码
        → 客户付款 → APK 监听到账
        → 系统扣码 owner 余额 + 按 rate 给上级分成
        → 触发 hook → 邮件/TG 推送码 owner
        → 点【确认到账】→ Order::complete → 回调客户商户
