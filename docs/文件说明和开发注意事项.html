🚨 下次开发必须注意的事项

A. 环境（本地 PowerShell）

A1. 中文写文件

症状：写入中文后变乱码、搜索匹配不到。

# 正确
[System.IO.File]::WriteAllText($f, $c, (New-Object System.Text.UTF8Encoding($false)))

# 错误（会加 BOM 或按 GBK 写）
Set-Content $f $c
$c | Out-File $f

A2. here-string 内容里不能有结束标记

PowerShell 单引号 here-string 的结束标记是「行首的单引号 + at 符号」。如果内容里出现这个序列（尤其在行首），here-string 会提前结束。

解决：内容里的这个序列要改成文字描述，或改用 VS Code 直接编辑 HTML。

A3. 注释用井号

PHP 的双斜杠、HTML 的尖括号在 PowerShell 里都不是注释，会被当命令执行。

A4. 美元括号会被 PS 当表达式执行

写 bash 命令时，shell 里的日期语法会被 PS 优先执行，导致报错。

# 错误：会触发 Get-Date
tar -czf backup_DATE_TAG.tar.gz

# 正确：写占位符，之后 Replace
# 或先写到临时文件再读进来

A5. 大段 HTML 不要贴 PowerShell

超过 50 行 HTML 会被 PS 逐行当命令执行，产生大量报错。

正确做法：

  • 用 VS Code 直接打开 .html 文件粘贴
  • 或写到临时 .txt 文件再读取
  • 或分段追加（每段 < 100 行，且不含 here-string 结束标记）

B. PHP 8.2 语法

B1. 变量 dollar-brace 已废弃

// PHP 8.2 会警告
"dollar-brace-name"

// 改用
"brace-name"

B2. use Exception 无效

// 顶级命名空间不能 use 全局类
// 直接省略，PHP 自动找全局 Exception
// 或写反斜杠 Exception

B3. PHP_BINARY 在 Apache 下是 httpd.exe

Apache 环境下 PHP_BINARY 指向 httpd.exe，不是 php。改探测式：

$phpBin = '';
foreach ([
  'D:\\phpstudy_pro\\Extensions\\php\\php8.2.9nts\\php.exe',
  'C:\\php\\php.exe',
  '/www/server/php/82/bin/php',
  '/usr/bin/php'
] as $cand) {
    if (is_file($cand)) { $phpBin = $cand; break; }
}
if (!$phpBin) $phpBin = 'php';

B4. 类型严格

字符串当数字用可能报警，用 (int) / (float) 显式转换。

C. 数据库

C1. pay_order 主键是 trade_no

没有 id 字段，按 trade_no 查询/排序。

C2. pay_record 时间字段是 date

不是 addtime。

C3. key 是 MySQL 保留字

必须用反引号包裹：SELECT 反引号key反引号 FROM pay_user。

C4. pay_user 字段命名

是 pay_minmoney / pay_maxmoney（不是 paymin/paymax）。

C5. pay_qrcode 没有 type/name

用 channel / remark 字段。

C6. ext 是 JSON

提取：SELECT JSON_UNQUOTE(JSON_EXTRACT(ext, 美元.qrcode_uid)) FROM pay_order

C7. PDO 不混用参数类型

命名参数和位置参数不能同时用，会报 HY093。

// 全命名
$DB->getRow("SELECT * FROM t WHERE uid=:u LIMIT 1", [':u'=>1]);

// 或全位置
$DB->getRow("SELECT * FROM t WHERE uid=? LIMIT 1", [1]);

D. 业务逻辑

D1. 码商代收扣款顺序

  1. 检查 ext.qrcode_uid
  2. 若 qrcode_uid 不等于 order.uid：
    • 查 qrcode_uid 余额
    • 余额不足 → 拒绝完成（回滚 status）
    • 扣 qrcode_uid 余额
    • 查 qrcode_uid 的 upid 和 rate
    • rate > 0 → 给 upid 加分成
  3. 更新码统计

D2. 推送目标 = 码 owner

hook_order_paid.php 里的 pushUid 优先取码 owner。

D3. 邮件分支优先级

  1. 码级邮件配置（pay_qrcode.mail_enabled=1 且有 mail_to）
  2. 下级推送资料（pay_user.sub_push_status=1 且有 sub_push_email）
  3. 平台商户邮件（pay_user_botconfig.mail_enabled=1）
  4. TG 推送

D4. 服务期拦截点

  • includes/lib/api/Pay.php — 收款前
  • paypage/notify_listen.php — APK 上报前
  • paypage/license.php — APK 激活时

D5. 3 级封顶

getSubTree / pickWithChildren 的 depth 上限都是 3。

E. 文件改动流程

  1. 改前备份（Copy-Item 加时间戳后缀）
  2. 用行号定位或单行 Replace（不要大段切片）
  3. 改完跑 php -l 做语法检查
  4. 测试：浏览器/curl 走一遍
  5. 不行就恢复备份

F. 上传 / 部署

F1. 绝不传

  • config.php
  • telegram/config.php

F2. 上线必删

  • _dev_login.php
  • _test.php / _mini.php
  • _test_*.php / _sim*.php / _ft*.php / _gen*.php / _pb*.php
  • notify_receiver.php（测试端）

F3. 打包排除

tar 打包时排除：备份、测试文件、config.php、runtime、日志。

F4. 线上 CLI PHP 是 7.4

站点 PHP 8.2，但 CLI 是 7.4。用 /www/server/php/82/bin/php 指定。
