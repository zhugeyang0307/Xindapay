【用户操作偏好 — 务必遵守】
═══════════════════════════════════════════════════════

命令风格：
1. 一条命令干完一件事，不分散
2. 不要长篇解释，只要命令 + 结果
3. PowerShell here-string（@'...'@）是主力写法
4. 写中文/PHP/HTML 用：
   [System.IO.File]::WriteAllText($path, $content, (New-Object System.Text.UTF8Encoding($false)))
5. 禁止用 Set-Content 写中文（GBK 编码 PHP 读乱码）
6. 改文件前先备份：Copy-Item $f "$f.bak.$(Get-Date -Format 'yyyyMMddHHmmss')"
7. 改完必跑：& $phpExe -l 文件
8. 不要在回答里连续输出带 "PS D:\...>" 提示符的命令
9. 用行号或纯 ASCII 锚点匹配，不靠中文匹配

here-string 坑：
- ❌ 绝不在 @'...'@ 里再包 @'...'@（PS 解析失败）
- 一份 HTML 太长 → 分 2-3 次 AppendAllText，每次 < 100 行
- 想写 PHP 的 $var → 用单引号 here-string 直接写
- ❌ 不用 \" 转义，正确：`` `" `` 或单引号字符串里直接写 "

沟通习惯：
- 用户会贴终端输出
- 用户说"继续"、"下一步"、"ABC" → 继续
- 用户说"停"或换话题 → 停
- 用户说"跑完贴回来" → 用户会贴输出
