👥 下级操作手册

面向二级/三级子商户（码商）

一、账号准备

1.1 接收账号

上级创建后会给你账号密码，用它登录 https://pay.yunzexinda.com/user/login.php。

1.2 首次登录要做的事

  1. 修改密码（我的账号 → 修改密码）
  2. 填写实名信息
  3. 配置推送资料（重要！）
  4. 上传收款码
  5. 绑定 APK 激活码

二、上传收款码

2.1 步骤

  1. 后台 → 收款工具 → 收款码管理 → 新增
  2. 上传微信/支付宝收款码图片
  3. 选择渠道（alipay_personal / wechat_personal / aggregate_both 等）
  4. 填备注、限额
  5. 保存
你的码会被上级派单用：上级商户下单时，系统会优先用自己码，不够时用你的码收款。

2.2 码的扣款机制

客户付款 200 → 你微信实际收到 200
          → 系统扣你"系统余额" 200
          → 上级按 rate 分成（如 3% = 6）
          → 你系统余额实际 -200，上级 +6

所以你的系统余额必须充足，否则接不了单。

2.3 让上级给你加余额

  1. 联系上级
  2. 上级在「下级商户 → 编辑」里给你加余额
  3. 你余额增加即可接更多单

三、推送资料配置

3.1 为什么必须配

客户付款后，系统要通知你（钱进你微信了，让你核对）。不配收不到任何通知。

3.2 填写位置

后台 → 推送 → 我的推送资料

3.3 三种通知方式

方式字段说明
📮 邮箱接收邮箱收到"新订单到账"邮件
📨 SMTP 发件SMTP 服务器/用户名/密码用自己邮箱发件（可选，不填用上级的）
💬 TGTelegram Chat ID收到 TG 消息

3.4 提交后要上级审批

提交后状态变「⏳ 待审批」，上级通过后才生效。

四、APK 激活与使用

4.1 领取激活码

  1. 后台 → 收款工具 → 我的激活码
  2. 点「领取」，每次 +1，最多 3 个
  3. 每个激活码对应一台手机

4.2 安装配置

  1. 下载 APK 到安卓手机
  2. 打开 APP → 输入激活码
  3. 授权：通知监听、悬浮窗、自启动、电池优化白名单
  4. 保持 APP 后台常驻（勿被系统杀）

4.3 检查是否在线

APP 内应显示「已连接」状态，或上级后台可看你的 license 心跳。

五、订单通知

5.1 邮件通知

收到主题为「新订单到账」的邮件，含：

  • 商品名
  • 金额
  • 订单号
  • 「✅ 确认到账」按钮（点击完成订单）
  • 「❌ 忽略」按钮（拒绝）

5.2 TG 通知

TG 收到消息 + 内联按钮「✅ 确认到账 / ❌ 忽略」，点击后完成订单。

5.3 点确认后的流程

点「确认到账」→ mail_confirm.php / TG callback
             → Order::complete(trade_no)
             → 扣你余额 + 上级分成
             → 回调客户商户 notify_url

六、上传账单给上级核对

6.1 为什么上传

你收款的实际流水要交给上级核对，避免争议。

6.2 上传步骤

  1. 微信/支付宝 App → 导出账单（用于个人对账）
  2. 收到邮件（微信是加密 ZIP，密码在「服务通知」里）
  3. 后台 → 对账单管理 → 上传
  4. 选文件 → 微信 ZIP 需填密码 → 提交
  5. 系统自动解析入库

6.3 支持格式

格式平台操作
ZIP（无密码）支付宝直接上传
ZIP（加密）微信填密码后上传
CSV / TXT聚合码/其他直接上传
XLSX聚合码直接上传

6.4 怎么导出账单

支付宝：

  1. 支付宝 → 我的 → 账单
  2. 右上角 ··· → 开具交易流水证明 → 用于个人对账
  3. 选时间 → 填邮箱
  4. 收到 ZIP（无密码）→ 直接上传

微信：

  1. 微信 → 我 → 服务 → 钱包 → 账单
  2. 右上角 ··· → 常见问题 → 下载账单
  3. 选「用于个人对账」→ 选时间 → 填邮箱
  4. 邮件收到加密 ZIP，密码在微信「服务通知」里
  5. 上传 ZIP + 填密码

七、查看自己的账

7.1 资金明细

后台 → 经营数据 → 资金明细。每一笔余额变动（收款扣款、上级划款）都记录。

7.2 对账中心

后台 → 经营数据 → 对账中心。看自己的收款、上级的分成。

八、常见问题

Q1：客户付了钱但订单没完成？

  • APK 是否在线
  • 金额/时间是否在 10 分钟内匹配
  • 系统余额是否够扣

Q2：收不到推送通知？

  • 推送资料是否已通过上级审批
  • SMTP 配置是否正确
  • TG Chat ID 是否对
  • 邮箱垃圾箱

Q3：接不到订单？

  • 系统余额是否充足（余额不足会拒单）
  • 收款码是否启用
  • 收款码限额是否匹配订单金额

Q4：上级能看到我的数据吗？

不能直接登录你的后台（已禁用模拟登录）。但上级能看到：

  • 你上传的账单（下级账单核对）
  • 你的收款码（下级收款码）
  • 你代收的订单（下级订单）
  • 你分给上级的金额（对账中心）

九、与上级对账

流程：

你上传账单 → 上级在「下级账单核对」看到
          → 点明细看每笔
          → 点对账自动匹配系统订单
          → 核对完点"删除"（软删）
          → 双方达成一致
对账无争议的关键：
  1. 你及时上传真实账单（微信/支付宝官方导出）
  2. 上级核对后能对上系统订单
  3. 系统按 rate 自动分润，双方都看得见
