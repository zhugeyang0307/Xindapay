收款码推送方案 · 完整说明

支持微信、支付宝个人码 H5 跳转，订单推送到个人或群，一键确认回调

一、整体方案

客户扫码 → 系统识别 → 拉起支付 → 客户付款
              ↓
        TG 机器人推单
              ↓
   个人私聊 / TG 群 / APK 监听
              ↓
        点【✅确认到账】
              ↓
   商户系统秒收回调

核心：钱直达商户收款码账户，系统只做消息与回调，不碰资金。

四、推送方式（三种）

方式 1：推送到个人私聊（推荐）

速度：约 60 条/分钟（不限流）

配置：

上传码时只填一个字段：

优点：

  • 私聊限速宽松（60/分钟）
  • 只有你能点，安全
  • 手机随时收，不用拉群

推荐给：个人商户、单账号收款

方式 2：推送到 TG 群

速度：约 17 条/分钟

配置：

推送目标：群ID（负数 -100xxx）
操作人TG ID：允许点确认的人

优点：

  • 多人协作
  • 群里点确认，团队都能看

缺点：

  • 群限速严格（20/分钟）
  • 人多可能误点

推荐给：团队/多客服

方式 3：APK 监听自动回调

速度：约 200 条/分钟

配置：

  • 旧安卓手机安装监听 APK
  • 自动抓取到账通知
  • 无需人工确认，直接回调

优点：

  • 全自动
  • 无人值守
  • 最快

缺点：

  • 需要旧安卓机
  • 按实际使用配置设备，不单独按笔收费

推荐给：无人值守、批量收款

点击【✅确认到账】后：

  1. 消息就地变成"✅已确认到账"
  2. 显示操作人 + TG ID + 确认时间
  3. 商户系统秒收 TRADE_SUCCESS 回调
  4. 订单状态更新为已支付

限流解决方案：系统内置 Redis 队列 + 多码分流，永不掉单。

十、常见问题

Q1：钱去哪了？

A：直达商户自己上传的收款码账户（微信/支付宝），平台不碰资金。

Q2：客户付款后多久收到回调？

A：点确认后立即回调，通常 < 1 秒。

Q3：推送目标必须和 bot 私聊过吗？

A：必须。TG 规定用户要先和 bot 发过消息。让目标用户去 bot 点 START 即可。

Q4：一个码能推给多个人吗？

A：不能。要多人看 → 把 bot 拉进群，填群 ID。

Q5：怎么改推送目标？

A：收款码管理 → 编辑 → 改推送目标 → 保存。

Q6：收款码换账号了怎么办？

A：上传新码 → 删旧码。旧码上的未完成订单不受影响。
