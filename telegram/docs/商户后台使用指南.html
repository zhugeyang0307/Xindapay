👑 商户老板后台使用指南

从开号到收款，3 分钟全面掌握

📱 把后台变成手机 App

无需下载安装包，添加到桌面即可全屏运行，不占内存。

  • 苹果手机 (iPhone)：使用 Safari 浏览器打开后台网址 -> 点击底部【分享】图标 -> 选择【添加到主屏幕】。
  • 安卓手机：使用 Chrome 或 夸克浏览器打开 -> 点击菜单【三条杠】 -> 选择【添加到主屏幕】。

🔔 开启语音播报（防漏单）

如果怕漏掉订单，请务必开启语音播报：

  1. 在手机 App 底部点击 【我的】。
  2. 找到 【新订单语音播报】，把开关打开。
  3. 手机弹出“是否允许通知”时，点击 【允许】。
  4. 开启后，有订单会自动响铃并震动。

💳 如何给员工（下级）开通账号？

你可以无限添加下级员工为你收款：

  1. 电脑或手机后台，点击左侧菜单的 【下级商户】 -> 【创建下级】。
  2. 填写员工账号、密码，点击提交。
  3. 创建成功后，在列表中点击 【一键复制】。
  4. 把复制好的专属链接、账号、密码通过微信发给员工。员工必须点这个专属链接才能登录。
💡 员工登录后，你可以在列表中看到他今天收了多少款。如果员工要挂 APK，在列表里点击【进入后台】帮他分配激活码。

🤖 如何配置 TG 机器人推送？

想让机器人自动在群里播报订单，或者发送确认按钮：

  1. 去后台左侧菜单找到 【推送中心】 -> 【机器人管理】。
  2. 按页面提示，去 Telegram 找 @BotFather 申请一个机器人 Token 填入。
  3. 点击 【获取我的 TG ID】，发给机器人 /id 拿到数字 ID，填到页面上。
  4. 打开 【新订单推送渠道】 的开关。

📧 邮件推送确认配置

如果你不想用 TG，也可以用邮件接收订单：

  1. 进入 【推送中心】 -> 【邮件推送设置】。
  2. 填入你的接收邮箱。
  3. 标准商户必做：填入你的 SMTP 服务器、账号、授权码（比如 QQ 邮箱的授权码），否则平台无法帮你代发。

💵 服务续费与充值说明

  • 服务说明：开户即用，不抽成，不按笔收费，收多少拿多少。
  • 如何充值：左侧菜单 【服务与充值】 -> 【USDT 充值】，系统会自动生成充值地址，转入后自动到账。
