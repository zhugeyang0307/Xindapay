## 二、商户绑定主机器人

商户可使用平台默认机器人（@xindawangluo1_bot）接收订单推送。

### 2.1 绑定到私聊

- TG 私聊 @xindawangluo1_bot

- 发送：/绑定 你的UID

- 收到"已绑定"即成功

### 2.2 绑定到群

- 把 @xindawangluo1_bot 拉进群

- 给管理员权限（能发消息即可）

- 群里发送：/绑定群 你的UID

- 收到"已绑定"即成功

## 三、商户自建机器人

见《机器人创建.md》文档。

- @BotFather → /newbot → 拿到 Token

- @userinfobot → 拿个人 TG ID

- 商户后台 → 机器人管理 → 填写

### 3.2 获取群 ID

## 六、常见问题

### Q1：命令没反应？

- 群里：需要 @机器人 再发命令（如 @xindawangluo1_bot 查 T地址 TRxxx）

- 私聊：直接发即可

- 检查拼写：中文/英文命令都要准确

### Q2：查 TRON 返回"地址未激活"？

- TRON 地址首次收到转账后才激活

- 新地址无余额是正常的

### Q3：监控地址会持续推送吗？

- 是的，一旦监控，地址有 USDT 转入/转出就会推给你

- 取消：取消监控 T地址 地址

### Q4：可以同时绑定多个群吗？

- 目前一个商户支持绑定多个群，都用同一个 bot 推送

- 群 ID 只能填一个；多个群请把 bot 拉进总群

# 信达支付系统 · TG 推送限流说明与解决方案

生成时间：2026-10-13

## 一、TG 官方限制（实测）

| 维度 | 限制

| 单群消息频率 | 约 20 条 / 分钟

| 单 bot 全局 | 约 30 条 / 秒

| 触发惩罚 | 首次 30-60 秒

| 编辑消息 | 同样受限

报错样例：{"ok":false,"error_code":429,"description":"Too Many Requests: retry after 41"}

## 二、系统解决方案

### 方案 1：Redis 队列 + 每群独立限速

商户下单 → 秒写入 Redis → Worker 单线程消费（每群 ≥3.5 秒/条）→ TG 永不限流

### 方案 2：多码绑多群

商户上传 N 个收款码，每码绑不同群，订单按码分流。

容量 = N × 17 条/分钟

### 方案 3：组合方案（终极）

Redis 队列 + 多群分流 + 每群独立限速

## 三、容量估算

| 群数量 | 每分钟 | 每天

| 1 个群 | 17 条 | 约 2.4 万单

| 4 个群 | 68 条 | 约 9.8 万单

| 10 个群 | 170 条 | 约 24 万单

## 四、商户操作步骤

- 创建 TG 群 → 拉 bot 进群 → 设管理员

- 群里发 /id 获取群 ID（格式 -100xxxxxxxxxx）

- 商户后台 → 收款方式管理 → 上传码 → 绑定群 + 操作人 TG ID

- 保存

- 每多绑 1 个群，容量增加 17 条/分钟

## 五、常见问题

Q1：点【确认到账】提示"无权操作"？

A：你的 TG ID 不在该群操作人列表。群里发 /加操作人 @你的用户名 添加。

Q2：订单消息延迟？

A：队列排队，最多 3.5 秒 × 队列长度。增加群数量可减少延迟。

Q3：订单推送失败？

A：检查 bot 是否被踢出群、是否被禁言、群 ID 是否正确。查日志：queue/logs/worker.log

Q4：为什么不能一次推很多条？

A：TG 官方限制，任何 bot 都无法绕过。唯一方案：多群分流 + 队列。

## 六、注意事项

- 不要试图绕过限流，TG 检测到会封 bot

- 不要多个 bot 打同一个群，会叠加限流

- 每群至少留 1 个操作人

- 群 ID 是负数（-100xxxxxxxxxx）

- 操作人 TG ID 是正数（7xxxxxxxxx）
