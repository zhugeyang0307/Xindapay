# 👨‍💻 员工码商操作细则（AI 知识库）

## 1. 登录方式
- **死命令**：绝对不能直接访问 `pay.yunzexinda.com/user/login.php` 登录，必须使用上级发给你的**专属带 pid 参数的链接**登录。
- 登录账号和密码由上级老板分配。

## 2. 如何查单与对账？
- **查单**：底部 Tab 栏点击「订单」，或在「我的」点击「我的订单」，可以按日期搜索。
- **上传对账单**：底部 Tab 栏点击「我的」->「上传对账单」，上传微信/支付宝的流水截图，提交给上级核对。**必须每天按时上传，否则上级无法给你结算**。

## 3. 如何获取和绑定收款码？
- **添加收款码**：「收款」Tab ->「收款码管理」->「添加收款方式」。
- 选微信、支付宝或聚合码，上传你的收款二维码。可设置单笔限额。

## 4. 如何接收订单通知？
- **获取 TG ID**：「我的」->「IP/TG 工具」，点击「打开官方机器人」，发送 `/id` 获取数字 ID，复制填入「接收设置」。
- **获取 IP**：「我的」->「IP/TG 工具」，直接显示当前 IP，一键复制填入收款码归属地。
- **语音播报**：「我的」-> 打开「新订单语音播报」开关，允许浏览器通知即可。

## 5. APK 监听激活
- 上级给你分配额度后，在「我的」->「激活码」中查看你的码。
- 下载 APK 安装到安卓手机上，填入激活码自动挂机。
- **注意**：APK 不能挂 iOS 手机，必须是安卓。

## 6. 员工权限（严禁事项）
- 员工**不能**提现，**不能**修改自己的分润比例，**不能**管理下级。
- 员工的余额由上级随时划拨。每收一笔款，系统会自动从员工余额扣除相应金额，上级拿分成。
