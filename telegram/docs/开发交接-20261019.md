# XindaPayusdt 项目开发交接文档 (2026-10-19)

## 一、本次已完成的模块与变更
### 1. 树形层级与默认分组 (之前已完成)
- 后台商户列表、商户端下级列表：已实现树形缩进展示 (L1 -> L2 -> L3)。
- 注册/创下级默认分组：自动赋予 gid=4 (标准商户组)。

### 2. 手机端原生 App 重构 (核心)
- **双端隔离**：`user/head.php` 和 `user/foot.php` 注入了拦截器，电脑访问保持原貌，手机端自动套用 `m_head.php` 和 `m_foot.php` 的 App 骨架。
- **原生 UI**：底部 TabBar (首页/订单/收款/资金/我的)，顶部极简悬浮导航。
- **专属工作台**：`user/app_me.php` 已区分身份。上级老板看到完整功能，码商（sub_level>=2）看到极简 6 宫格。
- **PWA 支持**：生成了 `manifest.json` 和 `app-icon.svg`，支持添加到桌面。

### 3. 员工端 (码商) 权限与功能精简
- **免强制 2FA**：`user/head.php` 中已放行 sub_level>=2 的用户，不再强制跳转绑定谷歌验证器。
- **极简激活码**：`user/license.php` 中，码商只能看激活码列表和下载 APK，隐藏服务状态、领取按钮。
- **专属测试页**：新增 `user/coder_test.php`，码商在这里只能看当前 IP 和获取 TG ID，不再看复杂的邮件/下级测试。
- **推送设置精简**：`user/sub_push.php` 中，码商只填 TG ID 和接收邮箱，隐藏 SMTP 和测试发件按钮。

### 4. 推送与机器人逻辑 (核心修复)
- **多群支持**：`user/telegram.php` 提示支持逗号分隔多群。`telegram/hook_order_paid.php` 已支持循环发送。
- **专码专群推送**：`pay_qrcode.group_id` 改为 varchar。订单分配到的码如果绑定了群，无视默认群，强制精准推送到专属群。
- **消息精简**：TG 推送模板移除了商品名、时间等废话，第一行大字显示【收款人：备注】。
- **群聊闭嘴**：所有机器人（平台/自建）在群聊中，如果没有匹配到明确指令，不再乱弹文字，静默处理。自建机器人拦截了误发的 `/绑定群`。
- **/id 秒回**：在 `bot.php` / `customer_bot.php` 的最开头加了拦截，发 `/id` 直接秒回 ID，绝不被 AI 拦截。
- **浏览器智能跳转**：`submit.php` 加了拦截，如果是浏览器直接访问，自动 302 跳转到真实的收银台，不显示 JSON 代码。

### 5. 授权码与逻辑修正
- **注册送 3 码**：`includes/lib/Service.php` 中，注册体验自动生成 3 个截止 11-01 的体验码。已给历史商户手动补发。
- **登录回退修复**：`user/login.php` 修复了带 `pid` 的专属链接被强退到首页的 Bug。
- **加余额崩溃修复**：`user/sub_edit.php` 头部致命语法截断修复，新增 Ajax 加减余额接口。
- **找码 Bug 修复**：`plugins/mapay/mapay_plugin.php` 修复了 PDO 绑定多出双引号导致查不到码、以及 channel 匹配报错的致命 Bug。
