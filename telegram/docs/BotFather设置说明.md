# BotFather 机器人设置完整教程

本文档教你如何给 Telegram 机器人设置：头像、简介、关于、命令菜单、群隐私

适用于：主机器人 @xindawangluo1_bot、客服机器人 @xindapay1H5_bot

## 一、BotFather 是什么

BotFather 是 Telegram 官方的机器人管理工具。所有 Telegram 机器人都通过它创建、配置、管理。

- 找它：TG 搜索 @BotFather（带蓝勾）

- 点 START 开始

- 所有命令都是 /xxx 格式

## 二、命令速查

| 命令 | 作用

| /newbot | 创建新机器人

| /mybots | 列出我所有的机器人

| /setname | 改机器人名称

| /setdescription | 改简介（用户点开前看到）

| /setabouttext | 改关于（资料页显示）

| /setuserpic | 改头像

| /setcommands | 设置命令菜单

| /setprivacy | 群隐私模式开关

| /token | 查看 Token

| /revoke | 重置 Token

| /deletebot | 删除机器人

## 三、详细步骤（推荐用 /mybots 菜单）

所有操作都可以通过 /mybots 的按钮界面完成，不用记命令。

### 1. 换头像

操作：

1. TG 搜 @BotFather → 发送 /mybots

2. 点你要设置的机器人

3. 点 Edit Bot

4. 点 Edit Botpic

5. 上传图片

图片要求：

| 项 | 要求

| 格式 | PNG / JPG

| 尺寸 | 512×512（最小 200×200）

| 形状 | 正方形（Telegram 会自动裁成圆形）

| 建议 | 品牌 logo + 主色 + 简洁文字

### 2. 设置简介（Description）

用户在点 START 之前看到的介绍文字。

操作：

1. /mybots → 选机器人

2. Edit Bot → Edit Description

3. 粘贴文字 → 发送

限制：最多 512 字符，纯文本（支持 emoji，不支持 HTML）

### 3. 设置关于（About）

在机器人资料页显示的简短说明（在简介下方）。

操作：

1. /mybots → 选机器人

2. Edit Bot → Edit About

3. 粘贴文字 → 发送

限制：最多 120 字符

主机器人：信达支付系统官方主机器人 · TG 收款 / 源码授权
客服机器人：信达支付系统官方客服 · 7×24 小时在线

### 4. 设置命令菜单

用户点输入框左侧 / 或菜单按钮时弹出的快捷命令列表。

操作：

1. /mybots → 选机器人

2. Edit Bot → Edit Commands

3. 发送命令列表（每行一条）

#### 推荐命令列表

start - 打开主页
help - 使用帮助
id - 查看我的 TG ID
menu - 打开菜单

### 5. 群隐私模式（重要）

默认机器人只能收到 @自己 的消息，看不到群里其他消息。关掉后能在群里正常用命令。

操作：

1. /mybots → 选机器人

2. Bot Settings → Group Privacy

3. 点 Turn off

4. 看到 "Privacy mode is disabled" 即可

什么时候需要关？

• 希望群里 /id、/加操作人 等命令被识别

• 希望机器人看到所有群消息

什么时候不用关？

• 只用于点按钮确认（callback 不受隐私限制）

## 五、头像制作建议

#### 尺寸

- 512×512 px（推荐）

- 格式：PNG 透明 或 JPG

- 文件大小：< 1MB

#### 设计要点

- 避免复杂文字：小尺寸显示时看不清

- 居中构图：Telegram 自动裁成圆形，边缘会被切

- 高对比度：深底浅字 或 浅底深字

- 品牌色：深蓝 #0d47a1 + 青绿 #00c9a7

#### 在线工具

- Canva（canva.com）—— 免费模板

- Figma（figma.com）—— 专业设计

- 稿定设计（gaoding.com）—— 中文友好

## 六、常见问题

#### Q1：设置完不生效？

部分设置需要用户重新打开对话才能看到。让用户退回聊天列表，再重新点进来即可。

#### Q2：简介能加链接吗？

不能。简介/About 都是纯文本，不支持 HTML/链接。

#### Q3：命令菜单能加 emoji 吗？

不能。命令菜单格式固定 命令 - 描述，描述部分是纯文本。

#### Q4：改名字后老用户还能找到吗？

能。用户名不变则链接不变。但显示名称会立即更新。

#### Q5：改 Token 会怎样？

/revoke 重置 Token 后，所有使用该 Token 的服务立即失效，需要用新 Token 重新配置。

#### Q6：群隐私关闭后有什么副作用？

机器人会收到群里所有消息。如果你用 AI 客服，会消耗更多 API 额度。建议只在需要时开。

#### Q7：能创建多少个机器人？

一个 TG 账号最多创建 20 个机器人。
