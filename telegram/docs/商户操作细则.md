# 👑 商户老板操作细则（AI 知识库）

## 1. 如何创建下级员工（码商）？
- **入口**：左侧菜单 ->「🏢 下级商户」->「创建下级」。
- **层级规则**：最高只能创建 3 级（A老板 -> B下级 -> C下级）。
- **操作**：填写员工账号、密码，提交。提交后在列表中点击【📋 一键复制】，将带有专属 `pid` 参数的链接发给员工。**员工必须通过专属链接登录，不能直接访问主站登录页**。
- **权限**：员工无法提现、无法管理下级、无法充值，只能收款和上传账单。

## 2. 如何给员工分配设备额度（APK）？
- **注册赠送**：新注册默认有 3 个激活码。
- **分配步骤**：员工自己登录后台 ->「收款工具」->「我的激活码」中自行查看并领取。
- **注意**：老板不需要代领，员工自己领取绑定即可。

## 3. 如何设置订单推送（防漏单）？
- **TG 推送**：
  1. 准备：去 Telegram 找 `@BotFather` 申请自己的机器人 Token。
  2. 配置：后台 ->「推送中心」->「机器人管理」，填入 Token，获取自己的 TG ID（发给机器人 `/id`），填入并保存。
  3. 开启：在页面顶部开启「新订单推送渠道」。
- **邮件推送**：
  1. 后台 ->「推送中心」->「邮件推送设置」。
  2. 填入接收邮箱。
  3. **必须配置 SMTP**（服务器地址、账号、授权码），因为标准商户组平台不提供代发服务。
- **语音播报**：
  1. 后台底部（或左侧）进入「我的」。
  2. 开启「新订单语音播报」开关，浏览器会申请通知权限，点【允许】即可。有单会直接响铃弹窗。

## 4. 如何查看下级收款与分润？
- **下级订单**：左侧菜单 ->「下级商户」->「下级订单」。
- **分润设置**：在「下级商户管理」列表，点击「编辑」，修改分润比例（rate）。下级每收一笔款，按比例从下级余额扣除，加到你的余额。
- **下级余额管理**：在列表中点击「编辑」->「增加余额/扣减余额」，用于给下级补充余额或扣除资金。

## 5. 如何配置收款码与智能路由？
- **上传收款码**：「收款工具」->「收款码管理」->「添加收款方式」。
- **智能路由**：系统支持按 IP 分配不同的收款码。上传时可选择「归属地区」和「绑定 IP」，实现异地客户自动匹配最近的收款人。

## 6. 系统服务说明
- 开户即用：平台不抽成，不按笔收费，收多少拿多少。
- 设备和接口按实际需求使用，相关配置可在后台统一管理。
