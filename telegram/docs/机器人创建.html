用你自己的 Telegram 机器人推送订单，不依赖平台默认机器人。

一、为什么要自建机器人

优势说明

稳定可靠不走平台机器人，平台维护不影响你
自定义可绑定自己的私人群、财务群

二、创建步骤（5 分钟）

第 1 步：找 @BotFather 创建机器人

  1. 打开 Telegram，搜索 @BotFather（官方认证账号）
  2. 私聊它，发送命令：/newbot
  3. 它问：给它起一个名字（中文可以，比如"我的收款助手"）
  4. 它问：给它起一个用户名（必须以 bot 结尾，比如 my_pay_notify_bot）
  5. 创建成功后，BotFather 会返回一段消息，里面有一行：

~~

Use this token to access the HTTP API:

7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

~~

复制这个 Token（很长的一串），这就是你机器人的密钥。

第 2 步：获取你的 TG 数字 ID

方法一（推荐）：

  1. 搜索 @userinfobot
  2. 私聊它，随便发一句
  3. 它会回复你的 ID（例如 1234567890）

方法二：

直接用你刚创建的机器人，私聊发 /id（配置完成后）

第 3 步：填到商户后台

  1. 登录 https://pay.yunzexinda.com/user/
  2. 左侧菜单 → 机器人管理
  3. 找到"自建机器人推送订单"面板
  4. 填写：

- 启用：勾选

- 自建机器人 Token：粘贴 BotFather 给的 Token

- 私聊 Chat ID：填你的 TG 数字 ID

- 群 ID（选填）：要推送到群才填

  1. 点【保存】
  2. 点【发送测试订单】→ 你的 TG 应收到测试消息

第 4 步（选填）：推送到群

  1. 把刚创建的机器人拉进你的 TG 群
  2. 给它管理员权限
  3. 群里任意人发送：/id
  4. 机器人回复群 ID（形如 -1001234567890）
  5. 复制群 ID，填到"群 ID"输入框
  6. 保存 → 点【发送测试订单】→ 群收到测试消息
提示：群 ID 优先。同时填了私聊 Chat ID 和群 ID 时，订单只推到群。

四、常见问题

Q1：保存后测试收不到消息？

  1. 先给机器人发条消息（/start 或任意内容）——Telegram 规定用户必须先主动跟机器人对话
  2. 检查 Token 是否复制完整（不能有多余空格）
  3. 检查 Chat ID 是否正确（纯数字）

Q2：Token 会泄露吗？

  • 商户后台加密存储，只有你和平台能看到
  • 一个 Token 只能绑定一个商户，重复使用会提示错误

Q3：想让订单同时推给多个人？

把机器人拉进一个群，把相关人都拉进群即可。订单会推到群，所有人都看得到。

Q4：不想用了怎么办？

在商户后台把"启用自建推送"取消勾选，保存即可。平台会切回默认机器人。

五、安全建议

  1. 不要泄露 Token：拿到 Token 就能控制你的机器人
  2. 定期更换：在 BotFather 里 /revoke 可重置 Token
  3. 群权限控制：不要把陌生人拉进收款群
  4. 开启登录提醒：在"登录安全提醒"面板里设置，防止账号被盗
