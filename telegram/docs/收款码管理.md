# 信达支付 · 收款码推送配置说明

适用于：商户后台 → 收款码管理 → 添加收款方式

## 一、核心概念

每张收款码可以配置一个推送目标，订单支付后会推送到这个目标，由该目标的人点【✅确认到账】。

| 推送目标类型 | 填法 | 效果

| 个人私聊 | 正数，如 7772671784 | 订单推给这个人的 TG 私聊

| TG 群 | 负数，如 -1003942712010 | 订单推到群里

## 二、归属地区（选填）

每个收款码可以标注一个归属地区（省 + 市），用于后续的智能路由分配——比如你有多张码分别属于不同地区，系统可以按客户 IP 归属地自动分配最近的收款码。

### 怎么填

- 省 / 直辖市：下拉选择（34 个选项：北京/上海/广东/...）

- 市 / 区：手动输入（如"深圳"、"朝阳"、"浦东新区"）

### 示例

收款码 1：广东 · 深圳
收款码 2：上海 · 浦东
收款码 3：北京 · 朝阳

客户扫码时，如果系统按 IP 路由分配收款码，广东省的客户优先匹配"广东"的码，上海的客户优先匹配"上海"的码。

💡 提示：归属地区是选填字段，留空不影响收款功能，只是不参与地区匹配。如果只有一张收款码或不需要地区路由，可以不填。

## 三、配置推送目标（个人）

## 四、配置推送目标（群）

### 群推送需要 2 个字段

推送目标：-1003942712010     ← 负数=群

- 群填负数，操作人填正数

- 操作人必须是该群成员

- 未填操作人的群，只有商户本人能点

- 它返回你的 ID（如 7772671784）

### 方法 2：用你自己的 bot

- 私聊你的自建 bot（如 @IPimessage_bot）

- 发 /id

- 机器人返回你的 TG ID

### 方法 3：找 @xindawangluo1_bot

- 私聊 @xindawangluo1_bot

- 返回你的 ID

## 六、如何获取群 ID

- 把 bot 拉进群

- 给 bot 管理员权限

- 群里发 /id（可能需要 @bot）

- 机器人返回群 ID（如 -1003942712010）

## 八、常见问题

Q1：只填推送目标，不填操作人，能点确认吗？

A：能。系统会自动把推送目标（正数）作为操作人。

Q2：填了群 ID，但没人能点？

A：群必须填"操作人 TG ID"，或让操作人在群里发 /加操作人 @xxx 添加。

Q3：换人了怎么改？

A：收款码管理 → 编辑 → 改推送目标 → 保存。下次订单就推给新的人。

Q4：一个码能推给多个人吗？

A：目前一个码只能填一个目标。要推给多个人 → 把 bot 拉进群，把他们都拉进群，填群 ID。

Q5：推送的目标必须先用过 bot 吗？

A：必须。TG 规定用户必须先和 bot 私聊过，bot 才能主动推消息。让目标用户去 @你的bot 点 START 即可。

Q6：收款码限速怎么办？

A：TG 单群限 20 条/分钟，私聊限 60 条/分钟。系统已内置 Redis 队列自动限速，多码绑不同目标可扩容。详见《TG 推送限流说明》。

## 1. 收款码是什么

    收款码 = 你（或你的下级）绑定的实际收款工具。客户下单后，系统从你可用的收款码里挑一个展示给客户，客户扫这个码付款。

### 它是怎么工作的？

【客户】扫码付款 → 【你的微信/支付宝】收到钱
        ↓
    【手机上的监听 App】监听到账
        ↓
    上报到【系统】→ 订单完成
        ↓
    【你】收到通知 → 点【确认到账】

### 为什么需要上传收款码？

      - 让系统认识你的收款工具：系统需要知道"这笔钱进了哪个账号"才能完成订单

      - 风控需要：客户 IP 归属地和收款码地区一致时，微信/支付宝风控更宽松

      - 分流需要：多个码可以按权重分流，单码被风控时其他码顶上

      💡 一个商户可以绑定多个收款码：微信 × N + 支付宝 × N + 聚合码 × N。系统会按"本人优先 → 下级补充"的顺序自动选。

### 完整操作步骤

    1

      打开新增弹窗点右上角「➕ 新增收款码」按钮。

    2

      选择平台微信 / 支付宝 / 聚合码（点一下卡片就选中，边框变蓝）。

    3

      选择收款码模式下拉框选择具体类型（如"微信赞赏码"/"支付宝个人码"等）。

      选了之后上方会显示蓝色的"从哪里获取"教程，照着操作微信/支付宝即可。

    4

      上传二维码图片（图片类）或 填写账号（账号/口令类）：

        - 图片类：点「选择文件」上传二维码

        - 账号类：填卡号/手机号/支付宝账号

        - 口令类：粘贴支付宝口令文本

    5

      填写备注（推荐填）方便自己识别，如"张三-微信"、"公司备用支付宝"。

    6

      配置限额（可选）：

        - 单笔最低/最高金额：只接收这个区间的订单

        - 金额浮动比例：防止客户总付整数被风控

        - 每日笔数/金额限制：达到后该码当天不再被派单

      留空或 0 = 不限制。

    7

      归属地区 + 绑定 IP（可选，但强烈推荐）：

      点「🔍 用我的 IP」自动填入真实 IP + 识别归属地；

      也可手动选省份。详见 第 6 章。

    8

      点「✅ 提交」保存。码出现在列表里，状态=启用。

### 图片类 vs 账号类 vs 口令类

    | 类型 | 需要填 | 举例

    | 图片类（大多数） | 二维码图片 + 备注 | 微信赞赏码、支付宝个人码

    | 账号类 | 收款账号 + 户名 + 开户行 | 微信银行、支付宝账号转账

    | 口令类 | 口令文本（粘贴整段） | 支付宝口令

      📷 图片上传技巧：

        - 用原图（不要截图、不要裁剪）

        - PNG 或 JPG 格式

        - 大小 1MB 以内

        - 不要加文字、白边、水印

### 推荐字段

    | 字段 | 推荐度 | 作用

    | 备注 | ⭐⭐⭐⭐⭐ | 自己识别用，如"张三-微信"

    | 归属地区 | ⭐⭐⭐⭐⭐ | 客户 IP 同地区优先匹配

    | 绑定 IP | ⭐⭐⭐⭐⭐ | 上传时记 IP，之后系统自动识别归属地

### 限额字段（选填）

    | 字段 | 说明 | 举例

    | 单笔最低金额 | 低于此金额不派单 | 填 10 = 只收 ≥10 元

    | 单笔最高金额 | 高于此金额不派单 | 填 5000 = 只收 ≤5000 元

    | 金额浮动比例 | 订单金额随机浮动 ±N% | 5 = 200 元订单 → 190~210 元

    | 每日笔数限制 | 当天累计到 N 笔后停用 | 填 50

    | 每日金额限制 | 当天累计到 N 元后停用 | 填 10000

      💡 限额设计建议：

        - 新号/敏感号：单笔上限设低（如 500），日限设紧（如 20 笔）

        - 老号/信任号：可以放宽（单笔 5000，日限 100 笔）

        - 浮动：建议开 3-5%，防整数金额风控

## 6. 绑定 IP 与地区（推荐）

    上传收款码时可以给它绑定一个 IP，系统会自动识别这个 IP 的归属地（省/市/运营商），下单时按客户 IP 匹配。

### 为什么重要？

      - 📈 客户 IP 与收款码归属地一致 → 微信/支付宝风控更宽松 → 支付成功率提升 15~20%

      - 🔒 精准管控：哪个地区的客户走哪个码，一目了然

      - 🎯 结合「收款码智能路由」可以做出精细的分流策略

### 操作步骤

    1

      打开新增码弹窗收款工具 → 收款码管理 → ➕ 新增

    2

      滚到「绑定 IP（选填）」在「归属地区」下方。

    3

      点「🔍 用我的 IP」自动填入你当前 IP + 显示归属地

      ⚠️ 如果你开了 VPN / 代理，请手动输入真实 IP

    4

      保存后系统自动把 IP 归属地写入码的 bind_province / bind_city

### 匹配逻辑（下单时）

客户下单
    ↓
系统查客户 IP → 得到省份（如：广东）
    ↓
候选码里筛选：
    · 码的 region_province = 广东？→ 命中
    · 码的 bind_province  = 广东？→ 命中
    ↓
命中码全部作为候选，按权重随机选一个

      💡 两种地区配置都行：

        - 手填 province：确定性高，但需要手动选

        - 绑定 IP 自动识别：省事，但 IP 变了不会自动更新

      建议只用一种，避免混乱。

      IP 归属地识别不准？

        - VPN / 代理 IP 会被识别为代理所在地

        - 4G/5G 手机 IP 可能跨省（运营商出口）

        - CDN 会显示 CDN 机房 IP

      遇到识别偏差 → 到「IP 检测」页核对，或手动选省份。

## 7. 常见问题

### Q1：上传二维码失败 / 识别不了？

      - 确认是原图（不要截图/裁剪/加白边）

      - 格式 PNG / JPG / JPEG，大小 1MB 以内

      - 聚合码必须原图，不要加任何修饰

      - 如果是微信"经营码"，要选"微信经营码"类型而不是"个人码"

### Q2：添加了码，但下单还是选不到？

      - 检查码的状态 = 启用（不是停用）

      - 检查金额是否在单笔最低/最高区间内

      - 检查是否已达每日笔数/金额限制

      - 到「功能测试中心 → 收款码选择测试」跑一遍看匹配结果

### Q3：能同时上传几个码？

    | 类型 | 上限

    | 微信/支付宝个人码、经营码等 | 不限

    | 微信银行、微信手机号、支付宝账号 | 不限

    | 支付宝口令 | 不限

    | 聚合码（3 种合计） | 不限

### Q4：多个码同时启用，客户下单会走哪个？

      - 先看你配的「收款码智能路由」规则

      - 没规则 → 客户 IP 与码归属地匹配的优先

      - 多个候选 → 按 weight（默认 100）加权随机

      - 都没命中 → 系统找下级码（最多 3 层）

### Q5：怎么让某个码不被用但又不想删？

    点列表里的「⛔ 停用」按钮，码不删除但不再被派单。想启用时点「✅ 启用」。

### Q6：金额浮动是干嘛的？

    让同一个码收到的金额不总是整数。比如订单 100 元，浮动 5% → 展示 95~105 元。防止风控识别异常。

### Q7：每日限额到了会怎样？

    该码当天不再被系统派单，其他码正常。次日 0 点自动重置。

### Q8：一个码能同时绑定多个地区吗？

    不能。一个码只能配 1 个省 + 1 个市。如果需要"这码同时服务多省"，建议配「收款码智能路由」规则。

### Q9：收款码被微信/支付宝封了怎么办？

      - 立即到「收款码管理」把该码停用

      - 上传新码补位（微信/支付宝重新申请）

      - 如果是下级码被封，通知下级尽快换码

### Q10：收款码有数量限制吗？

    没有限制，可以自由添加。但建议：

      - 定期检查已停用 / 已失效的码，及时删除避免被系统派单导致订单失败

      - 暂时不用的码，用「停用」代替删除（保留历史数据）

      - 码太多不好管理时，可以用「收款码智能路由」做分流
