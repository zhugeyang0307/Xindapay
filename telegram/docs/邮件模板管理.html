保存模板 · 一键导入活动 · 复用 HTML

1. 模板是什么

模板 = 保存好的 HTML 邮件正文，下次发营销邮件时一键复用，不用每次重写。

为什么要用模板？

  • 🕐 省时间：常用邮件存成模板，下次点一下就用
  • 📋 统一风格：所有营销邮件保持一致的品牌形象
  • 🔄 可复用：一个模板能建多个活动
💡 场景：新品通知模板、优惠券模板、节日祝福模板、老客户召回模板。

2. 创建模板

后台 → 邮件营销 → 邮件模板（/user/mail_marketing/templates.php）

操作步骤

1
点左侧「➕ 新建模板」（右侧表单自动清空）
2
填模板名 *如"双十一促销模板"（仅自己可见，方便管理）
3
填默认邮件主题（选填）用此模板建活动时，主题会自动填入
4
编辑 HTML 正文 *两种方式：
· 直接编辑：在文本框里写 HTML
· 导入 HTML：点「📁 导入 HTML 文件」选本地 .html 文件（自动填入）
5
点「创建模板」保存。左侧列表出现新模板。

3. 用模板建活动

3 种方式，随便选：

方式 1：从模板列表直接建（最快）

  1. 模板列表里找到该模板
  2. 点「✈️ 用此模板建活动」
  3. 跳到「新建活动」页，正文 + 主题自动填入
  4. 填收件人 → 提交

方式 2：建活动时从下拉选

  1. 新建活动页 → 正文区上方有「从模板导入」下拉
  2. 选一个模板 → 覆盖当前正文（会提示确认）
  3. 继续填收件人

方式 3：导入本地 HTML

  1. 新建活动页 → 点「📁 导入 HTML」
  2. 选本地 .html 文件（UTF-8 编码）
  3. 内容自动填入正文框
💡 最佳实践：把常用邮件存成模板（方式 1），以后建活动 1 秒搞定。

4. 管理已有模板

模板列表

每个模板显示：

  • 模板名 + 默认主题
  • 更新时间
  • 被引用次数（有多少活动用了它）

操作按钮

按钮作用
用此模板建活动跳到新建活动页并预填
查看引用列出所有使用该模板的活动
编辑点模板名进入编辑
删除 ×删除模板（不影响已创建的活动）
💡 删除模板不删活动：活动创建后已有正文副本，删模板不影响已有活动。

编辑模板

  1. 点模板名 或 右侧列表点该模板
  2. 修改内容 → 点「保存修改」
  3. 下次用此模板建活动，会用最新版本

5. HTML 编写参考

基本结构

<div style="max-width:600px;margin:0 auto;font-family:sans-serif;">
  <h1 style="color:#0d47a1;">标题</h1>
  <p>正文内容...</p>
  <a href="https://your-site.com/sale" 
     style="display:inline-block;background:#1677ff;color:#fff;padding:12px 24px;border-radius:6px;text-decoration:none;">
    立即抢购
  </a>
</div>

注意事项

  • ✅ 用内联样式（style="..."），不要用 <style> 标签
  • ✅ 宽度 600px（兼容大多数邮箱）
  • ✅ 图片用绝对 URL（不能是相对路径）
  • ✅ 链接要完整（含 https://）
  • ❌ 不要用 JS（邮箱会屏蔽）
  • ❌ 不要用表单（邮箱不支持）

可以用模板变量

正文里可写 {email} 占位符，发送时会自动替换成收件人邮箱。

💡 快速生成 HTML：用 W3School HTML 编辑器、VS Code，或直接用 Figma 导出 HTML。

6. 常见问题

Q1：导入 HTML 没反应？

  • 确认文件扩展名是 .html 或 .htm
  • 确认文件编码是 UTF-8（不是 GBK）
  • 文件里不能有 <script> 标签（会被过滤）

Q2：模板能分享给别人吗？

不能。模板是账号私有，其他商户看不到。

Q3：模板数量有限制吗？

不限。存多少都行，列表页最多显示 500 个。

Q4：删了模板，用该模板建的活动会怎样？

不受影响。活动创建时已复制正文副本，独立存在。

Q5：为什么我导入 HTML 后排版乱了？

  • HTML 里用了 <style> 标签（邮箱不认）
  • 用了外部 CSS 引用
  • 解决办法：把样式改成内联 style="..."

Q6：模板里能加图片吗？

可以，但要：

  • 图片上传到某个公网可访问的地址
  • 用绝对 URL：<img src="https://cdn.example.com/pic.jpg">
  • 不要超过 200KB（邮箱会屏蔽超大图）

Q7：多个模板能合并吗？

不能。但可以复制一个模板的内容到另一个模板里。
