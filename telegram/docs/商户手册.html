2. 实名认证

为什么必须做？

  • 未实名 → 无法收单（系统拦截）
  • 未实名 → 无法领取 APK 激活码
  • 未实名 → 无法创建下级

认证步骤

1
打开认证页后台 → 我的账号 → 实名认证
2
填个人信息姓名、身份证号、手机号
3
上传证件身份证正反面照片
4
提交审核1-24 小时出结果
审核不通过常见原因：照片模糊、信息不一致、证件过期。

5. 收款码智能路由

详细文档：🎯 收款码智能路由

是什么？

按客户 IP 归属地 / 权重规则自动选择最优收款码，支付成功率提升 15-20%。

3 种规则类型

类型说明
按省份把某省客户分配给指定码
按权重多个码按 weight 加权随机分流
全部（兜底）其他规则都不命中时用这组码

优先级

路由规则 → 客户 IP 省份匹配 → 权重随机 → use_count 最少 → 本人码优先 → 下级码

10. 下级商户

详细文档：👥 下级操作手册

10.1 3 级结构

A（一级）→ B（二级）→ C（三级）
· 最多 3 级
· 每级直接下级数量不限
· A 能管 B 和 C，B 只能管 C

10.2 创建下级

  1. 后台 → 下级商户 → 创建下级
  2. 填账号、密码、层级
  3. 提交后下级可登录

10.3 编辑下级

字段说明
分润比例（rate）下级收款时上级拿的百分比（0-50%）
收款权限关闭后下级无法收款
增加余额从上级余额划给下级
扣减余额从下级余额划给上级

10.4 码商代收机制

下级 B 帮上级 A 收款 200 元：
· 客户付款 200 → B 微信实际收到 200
· 系统扣 B 余额 200（B 系统余额 -200）
· A 按 rate 拿分成（如 3% → +6）
· 平台抽成 0

→ 下级必须保证余额充足，否则拒单

10.5 下级管理工具

页面作用
下级商户管理下级列表 + 编辑
下级订单看下级码收的所有订单
下级收款码开关下级收款码
下级账单核对看下级上传的账单 + 核对
下级推送审批审批下级推送资料

10.6 上下级隔离（重要）

⚠️ 系统已禁用上级一键切换登录下级功能。上下级各自独立登录，互不干涉。
上级只能通过专门的管理页面（下级订单/下级收款码/下级账单）查看下级数据，无法直接登录下级后台。

11. 账单核对

11.1 为什么需要？

下级码收的款（进下级微信），上级需要核对下级的真实流水是否对得上系统记录，避免争议。

11.2 上下级对账流程

下级 → 微信/支付宝导出账单 → 上传到系统
                ↓
上级 → 「下级账单核对」→ 看下级所有批次
                ↓
点「明细」看每条 + 点「对账」系统自动匹配订单
                ↓
核对完 → 点「🗑 核对完删除」（软删除）
                ↓
双方达成一致 → 记录可随时恢复

11.3 对账原理

按「金额一致 + 时间差 < 10 分钟」匹配：

结果含义
✅ 匹配系统订单和账单都有，正常
⚠️ 系统独有系统有但账单没记录（可能漏单）
❌ 账单独有账单有但系统没订单（用户直接扫码）

11.4 上传格式支持

格式平台操作
ZIP（无密码）支付宝直接上传
ZIP（加密）微信填密码后上传
CSV / TXT聚合码/其他直接上传
XLSX聚合码直接上传

11.5 软删除

点「🗑 核对完删除」是软删除：

  • 数据库记录保留
  • 普通列表不再显示
  • 「已删除」Tab 可查看 + 恢复

12. 常见问题

Q1：下单后客户看不到收款码？

  • 检查有没有启用的收款码（status=1）
  • 检查收款码限额是否覆盖订单金额
  • 检查系统服务期是否有效
  • 到「功能测试中心 → 收款码选择测试」看匹配结果

Q2：客户已付款但订单没完成？

  • APK 是否在线（App 显示"在线"）
  • 金额和时间是否 10 分钟内匹配
  • 码 owner 余额是否充足
  • 手动补单

Q3：邮件没收到？

  • 检查 SMTP 配置（邮件推送页）
  • 检查垃圾邮件箱
  • 查看发送状态（功能测试中心）

Q4：下级收不到推送？

  • 下级推送资料是否通过审批
  • 上级在「下级推送审批」页点「🧪 测推送」验证
  • 下级邮箱/TG Chat ID 是否正确

Q5：账户余额不足会怎样？

  • 下级余额不足 → 系统拒单（该码不被选）
  • 退款时余额不足 → 退款失败

Q6：服务期到期后数据还在吗？

在。数据永久保留，只是无法收单。续费后立即恢复。

Q7：能修改实名信息吗？

不能。实名信息一经审核不可修改。如填错联系客服。

Q8：怎么联系客服？

  • 后台 → 帮助 → 帮助中心（查文档）
  • 后台 → 帮助 → 提交工单
  • 或通过官方 TG / 邮件

Q9：能在手机浏览器操作吗？

可以。后台做了响应式，手机浏览器也能用。但配置类操作建议用电脑，体验更好。

Q10：多久能收到钱？

客户付款 → 你的微信/支付宝立即到账（微信/支付宝是即时到账）。系统只做确认和记录。
