

项目说明文档

Xindapay
基于易支付开发的多商户码商系统

一、项目概述
Xindapay 是一个基于 PHP + MySQL 的多商户收款系统，适用于支付平台、码商体系、商户结算、订单收款、异步回调、后台运营等场景。该项目具备商户管理、支付通道管理、订单处理、后台运营、结算统计、邮件通知、Telegram 消息通知等能力。

从仓库代码结构看，本系统偏向“支付中台 + 商户收款平台”的设计，支持多种支付类型和渠道接入，并具备较完整的后台控制功能。

二、技术栈
- 后端语言：PHP
- 数据库：MySQL
- 前端：HTML / CSS / JavaScript
- 依赖管理：Composer
- 运行环境：Apache / Nginx + PHP
- 主要文件：index.php、api.php、config.php、admin/、user/、paypage/、includes/

三、系统功能模块

1. 商户管理
- 商户注册、登录、密钥管理
- 商户状态审核
- 结算信息管理
- 商户余额、订单查询、退款权限控制

2. 支付下单
- 商户调用支付接口发起订单
- 支付页面生成订单
- 根据不同支付类型和通道进行路由
- 支付页面支持移动端收款体验

3. 多支付渠道支持
- 支付宝
- 微信
- QQ 支付
- 银行卡/网银支付
- 支付通道扩展能力

4. 订单与回调
- 订单生成与状态更新
- 异步回调处理
- 通知状态写入
- 支付确认、失败、退款等状态管理

5. 后台管理
- 订单查询
- 商户列表
- 结算管理
- 渠道配置
- 风控处理
- 系统设置
- 日志查看

6. 邮件与营销
- 订单确认邮件
- 商户通知邮件
- 商户营销邮件群发
- 邮件追踪与统计
- AI 邮件生成与优化

7. Telegram 通知
- 订单状态推送
- 系统通知
- 运营类提醒
- 监控与事件同步

8. 路由与安全
- IP 区域判断
- 路由规则
- 支付通道分流
- 日志记录和调试控制

四、仓库结构说明

核心目录说明：

- root/
  - index.php：前台入口
  - api.php：API 入口
  - config.php：基础配置文件
  - composer.json：依赖定义
  - cron.php：定时任务
  - notify.php：回调入口
  - submit.php：提交入口
  - gateway.php：网关相关
  - pay.php：支付相关
  - payok.php：支付成功处理
  - mail_confirm.php：邮件确认逻辑
  - user_bot_hook.php：用户机器人钩子

- admin/
  - 后台管理入口
  - 订单管理、商户管理、渠道管理、结算管理、权限设置等模块

- user/
  - 用户/商户中心模块
  - 包含商户后台和功能页

- paypage/
  - 收款页面逻辑
  - 用户付款入口

- includes/
  - 核心类库和公共函数
  - 系统通用逻辑层

- route/
  - 路由模块
  - 智能路由、IP 路由和转发逻辑

- mail_track/
  - 邮件追踪系统
  - 点击、打开、行为分析

- telegram/
  - Telegram 集成模块
  - 通知逻辑与数据库连接

- assets/
  - 前端资源、样式、图片和脚本

- vendor/
  - Composer 依赖库

五、业务流程

1. 商户创建账号
2. 配置收款参数
3. 商户发起收款订单
4. 用户完成支付
5. 平台回调验证
6. 更新订单状态
7. 发起结算
8. 管理后台查看数据
9. 记录日志和通知

六、系统特点

- 支持多商户模式
- 支付通道与商户分离
- 订单状态统一管理
- 适合中小型支付中台
- 管理后台功能较全
- 具备较强的代码扩展性
- 适合二次开发与商业部署

七、安全与部署注意事项

1. 敏感配置管理
以下文件包含系统关键配置信息，建议不要随意公开：
- config.php
- route/config.php
- mail_track/config.php
- telegram/config.php
- .env
- 日志文件
- 证书、密钥文件

2. 数据库安全
- 数据库用户名、密码、主机、端口需要单独保管
- 生产环境不建议直接写在公开仓库中

3. 日志脱敏
- 不要在日志中记录完整的支付密钥、token、key、sign、password、Authorization 等敏感字段
- 统一进行脱敏处理

4. 权限控制
- admin 后台必须限制访问
- 生产环境建议启用 HTTPS
- 所有关键 API 应增加校验

八、建议隐藏的敏感文件
如果是公开 GitHub 仓库，建议将以下内容加入 .gitignore，避免敏感配置和私密数据被提交：

```gitignore
# 基础配置
config.php
route/config.php
mail_track/config.php
telegram/config.php
.env
.env.*

# 日志与缓存
logs/
*.log
cache/
tmp/

# 数据库与备份
*.sql
*.bak
*.zip
*.tar.gz

# 证书与密钥
*.pem
*.key
*.crt
*.p12
```

如果你有真实部署环境，建议继续隐藏：
- 证书文件
- 支付平台私钥
- 商户加密密钥
- 运行日志
- 数据库备份
- 上传文件目录

九、部署建议
- PHP 7.4 及以上
- MySQL 5.7+
- Composer 依赖
- Apache/Nginx
- 配置虚拟主机
- 安全启用 HTTPS
- 关闭 debug 模式
- 关键模块严格校验

十、总结
Xindapay 是一个功能较完整的多商户支付收款系统，具备商户管理、支付通道管理、订单处理、后台运营、结算管理、邮件营销和 Telegram 通知等能力。该项目适合用于码商系统、收款系统、支付平台和第三方支付中台的二次开发。
